# Transmission constraints

Generation built faster than the wires to carry it produces curtailment: output that
exists and cannot be delivered. Constraint payments compensate generators for not
producing, which reads as waste and is usually cheaper than the reinforcement that would
avoid it.

Thermal limits on a line are a function of ambient temperature and wind, so dynamic line
rating can release capacity that a static rating leaves stranded. The measurement problem
is the obstacle, not the physics.

Interconnection queues have become the binding constraint in several markets. Studies are
sequential and each withdrawal reshuffles the ones behind it.
